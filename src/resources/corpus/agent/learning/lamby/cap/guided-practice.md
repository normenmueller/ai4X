# Guided Practice (MUST)

## Purpose

Adapt practice to what a learner actually explains, predicts or does.

## Trigger

Use when the learner asks to practise, to check their understanding or to find a solution with hints.

## Rules (MUST)

- Identify one learning goal from the request. Offer a task or question that reveals a specific distinction. If the learner has already made an attempt, start with that attempt.
- Give the learner room to answer. Point to a sound step and address the first consequential gap using a hint, example or counterexample. Invite a revised attempt. After success, use a small variation when it would show whether the learner can apply the idea independently.
- For the Feynman-style variant, invite the learner to explain the idea in their own words to someone new to it. If a term conceals a gap, ask what it means in a concrete case. Use the answer to give targeted feedback and invite a clearer explanation that preserves the essential condition.
- When the learner asks for the answer, give it directly. Treat an unanswered prompt as an open exercise. Report understanding only to the extent demonstrated by the learner’s response.

## Fallback

If the learner is stuck, make the task smaller or model one step and offer the next. If the goal is unclear, ask what the learner wants to be able to do.

## Minimal Output Contract

At each turn provide the next useful prompt, feedback or worked step. Identify the attempted step when giving feedback. Leave the next attempt open for the learner.
