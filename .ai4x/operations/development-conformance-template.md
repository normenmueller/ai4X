# Story conformance snapshot

Use with the [conformance check](development-conformance.md). Link existing evidence in place.

| Field | Record |
| --- | --- |
| Context | Date, Story, parent Epic if applicable, revision, checkpoint, responsible agent |
| Requirements | Scope and acceptance criteria, including any Story refinements |
| Conditional evidence | Design, design review, AI strategy, capability assessment. Give the evidence or the reason a step does not apply. |
| Delivery evidence | Implementation, criterion-to-test results, independent review. Mark later evidence as pending at the first checkpoint. |
| Challenges | Contradictions, unverified assumptions, missing tests |
| Review | High, medium and low findings, residual risk |
| Gate | Blocked or pass, reason, required corrections and owners |
| Next action | Authorized next step or specific decision requested from the PO |
