# Need to Capability

How does a human need become an Agentic Constellation fit for its purpose?

**Need-first discovery.** A structured conversation helps the user clarify why the work matters, what outcome they want, and how they will recognize success. The user confirms that intent before anyone chooses how to fulfil it.

**Curated agentic fulfilment.** From the confirmed intent, ai4X helps select the cognitive capabilities an agent or team needs. The proposed operating model describes who works with whom, how work moves between them, and which decisions need human approval. Once accepted, the versioned declaration can be used across agent hosts.

When one agent coordinates several specialists, that pattern of roles is the team’s *collaboration topology*, and it stays the same even if different agents fill those roles.
