# Need specification

How can we describe a need precisely enough to check its inputs and outputs?

The research [type model](Ai4x/Spc.hs) and [seven example needs](Needs.hs) express the relationship between the work requested and the artifacts it consumes and produces. The examples cover architecture, implementation, testing, review, requirements, AI strategy and capability governance. They explore which relationships can be checked mechanically and which still require human judgment.
