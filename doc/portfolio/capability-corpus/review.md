# Reviewing the capability corpus

Can someone facing a real task find the right capability and tell when to use it? Choose the domain or corpus revision to review. Use concrete tasks from project needs to test these four questions.

| Look for | How to check |
| --- | --- |
| Outdated guidance | Read the trigger and expected result against a current task. Identify wording that would lead someone to choose the wrong capability or produce an unusable result. |
| Overlap | Give neighboring capabilities the same task. If both appear to apply, explain what each would contribute and whether the distinction is visible to the reader. |
| Gaps | Identify a concrete need, the closest capability and the part of the work it leaves uncovered. |
| Misleading metadata | Compare the description with its stated exclusions, distinctions and sources. Check whether those details support the choice a reader would make. |

For each finding, record the affected capabilities, the task that exposed the issue and its likely impact. Recommend a change or explain what evidence is still needed. Prioritize findings that could repeatedly lead a team to select the wrong capability.
