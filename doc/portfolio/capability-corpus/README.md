# Capability corpus

What cognitive work can an agent draw on, and how can authors describe it precisely?

Each capability in the [corpus](../../../src/resources/corpus/capability/) describes a reusable unit of work. For example, [strategic fit evaluation](../../../src/resources/corpus/capability/strategy/evaluation/strategic-fit.md) helps assess whether an initiative fits a strategy. Different agents can use that same ability.

The [authoring guide](authoring.md) explains how to define a capability and distinguish it from others that might apply in the same situation.

The [review guide](review.md) explains how to examine the corpus for gaps, overlap, outdated guidance and misleading metadata.

The [governance drafts](../../../src/resources/corpus/governance/README.md) cover capability admission, review and release.
