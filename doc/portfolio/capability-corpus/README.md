# Capability corpus

What cognitive work can an agent draw on, and how can authors describe it precisely?

Each capability in the [corpus](../../../src/resources/corpus/capabilities/) describes a reusable unit of work. For example, [strategic fit evaluation](../../../src/resources/corpus/capabilities/strategy/evaluation/strategic-fit.md) helps assess whether an initiative fits a strategy. Different agents can use that same ability.

The [authoring guide](authoring.md) explains how to define a capability and distinguish it from others that might apply in the same situation.
