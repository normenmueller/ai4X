# Knob of Behavior (KOB)

**Design proposal · work in progress.**

KOB proposes giving each agent a role that a person can recognize and request by name. A capability describes something an agent can do. A KOB profile brings capabilities together for a recurring kind of work. For example, someone deciding which initiatives to prioritize could turn to Sigrid for strategic assessment. Someone coordinating architecture across those initiatives could turn to Hildegard for an enterprise-wide view.

The portfolio groups profiles by use case. Each agent has a role description, and curated bundles identify the capabilities that support its work. Mechthild approaches the same question from a project’s perspective. Her role is to start with a project's need, look for suitable capabilities and use them to design a project-local agent.
