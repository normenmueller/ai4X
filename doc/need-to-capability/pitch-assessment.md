# Assessing competing pitches

In the v1 design, a team had collected pitch ideas in a spreadsheet and needed to decide which to pursue first. For the team to explain its priorities, reviewers needed to judge each pitch against the same strategic criteria.

The proposed assessment capability would take each idea from the spreadsheet, express it in a common format and apply the agreed criteria. Reviewers could read the scores alongside the reasoning and use both to decide which ideas to prioritize.

If a team member corrected one pitch, the capability would reassess that pitch against the same criteria. The team could then compare its revised score with the others and see whether the correction changed its place in the ranking.

This historical example draws on journey 3 in the v1 *AI4x User Journeys* and scenario 3 in *AI4x Scenarios*.
