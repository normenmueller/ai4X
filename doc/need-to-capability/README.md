# Need to Capability

How does a human need become an Agentic Constellation fit for its purpose?

The [architecture poster](need-to-capability.png) and its [TikZ source](need-to-capability.tex) show the current target architecture. The earlier [user journey](user-journey.md) follows a user through scouting, curation and activation. It also explores direct access to an expert through `ask`. Commands and paths in the journey describe the proposed experience.

The [original design scenario](design-scenario.md) asks how one project would use both VS Code with Copilot and Codex CLI. Follow the [need specification](need-specification/README.md) for the inputs to curation and [runtime activation](../runtime-activation/README.md) for the choice of host.

[The first agent session in a new workspace](first-agent-session.md) takes the new team member’s perspective on activation. It records how the v1 design made the active agent, its skills and its host visible at startup.

[Updating an agent’s capabilities](capability-updates.md) follows a v1 maintainer from a pinned corpus revision to the reviewed bundle selected for the next session.

[Assessing competing pitches](pitch-assessment.md) illustrates how a team could use one set of criteria to prioritize ideas and revisit the ranking after a single pitch changed.
