# Assessing competing pitches

A team has collected pitch ideas in a spreadsheet. Which should it pursue first? To explain its priorities, the team needs to assess each pitch against the same strategic criteria.

The proposed workflow would first convert the spreadsheet entries into a common format. The assessment capability would then apply the agreed criteria to each pitch. Reviewers could read the scores alongside the reasoning and use both to decide which ideas to prioritize.

If a team member corrected one pitch, the capability would reassess that pitch against the same criteria. The team could then compare its revised score with the others and see whether the correction changed its place in the ranking.
