# Licensing ai4X

ai4X uses two path-based first-party licenses:

- Apache License 2.0 for executable software, tests, schemas, build automation, and tooling.
- Creative Commons Attribution 4.0 International for documentation, governance, declarations, and agent-consumable knowledge.

[REUSE.toml](REUSE.toml) is the machine-readable path authority and `LICENSES/`
contains the canonical license texts. There is no implicit repository-wide
default license.

Contributors must submit only material they are authorized to license and retain
third-party attribution. Adding unknown material, an incompatible excerpt, or a
new first-party license requires an explicit Product Owner decision.
